# Shared worker rules

The manager owns sequencing, delegation, and final reporting. Work only on your
assignment, including in a separate chat. Do not start another crew unless assigned.

- Read the supplied task files and relevant repository `AGENTS.md` before work.
- Write notes only to the exact assigned path under `tmp/crew-manager/<slug>/`. Never commit coordination files.
- State the completion protocol followed, checks and outcomes, failures, skips, uncertainty, and remaining work in your notes.
- Keep evidence in the notes and return a concise status with their path. Report blockers promptly, without routine progress pings or requests for acknowledgment.

In chat mode, follow [chat-mode.md](chat-mode.md) for authorization, handoff, and
read-status ordering. After sending the agreed handoff, finish without waiting
for the manager.
